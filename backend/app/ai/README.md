# DocuFin AI Module

## Scope & Architectural Role
This module encapsulates all AI, LLM, and Machine Learning workflows for financial document processing in DocuFin AI.

### Planned Submodules (Phase 2+)
- `extractors/`: Multi-modal document parsing (PDF tables, SEC 10-K/10-Q filings, financial disclosures).
- `embeddings/`: Domain-adapted financial embedding models.
- `rag/`: Vector search, semantic indexing, chunking strategies, and hybrid retrieval.
- `prompts/`: Versioned prompt templates for financial statement verification, anomaly detection, and ratio analysis.
- `evaluation/`: Hallucination detection, citation verification, and confidence scores.
